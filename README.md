# ArXiv-Org-Parser
Script that allows to parse most of the articles from arxiv.org. Here specifically are parsed articles in Physics, Mathematics and IT - 100 articles each.

It is important to mention that there is a structure in the html versions of the articles which differs from the two structures represented in the current script. I needed just some articles, so optimized my work by not changing the structure. You may need to do that if you like to process some particular articles.
